## 🚀 QUICK START

### For School Admins
```
1. Login to EduIMA
2. Click "School Page" in sidebar
3. Click "Edit Profile" to update banner, logo, description
4. Click "Create New Post" to publish content
5. Click "Comment" to moderate discussions
```

### For Other Users
```
1. Navigate to school page
2. Click "Follow" to subscribe
3. Click "Like" on posts
4. Click "Comment" to engage
5. Click "Report" to flag inappropriate content
```

### For Developers
```
1. API Base: http://localhost:5000/api/school-page
2. Models: /backend/models/School*.js
3. Controller: /backend/controllers/schoolPageController.js
4. Frontend: /frontend/src/pages/SchoolPageProfile.jsx
5. Database: /backend/database/migrations/2025-12-27-add-school-pages.sql
```
