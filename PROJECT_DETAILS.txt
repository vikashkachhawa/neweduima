--------------------------------------------------------------------------------
WHAT IS EDUIMA?
--------------------------------------------------------------------------------

Eduima is a full-stack multi-tenant school management system built for
educational institutions. It allows multiple schools to operate on a single
platform with complete data isolation, role-based access control, and a rich
set of tools for administrators, faculty, and students.

Beyond administration, Eduima includes a student-facing portal with social
features (forum, chat, social hub), fun learning games (Blockly-based coding
sandbox), and detailed faculty & student profiles.

--------------------------------------------------------------------------------
TECHNOLOGY STACK
--------------------------------------------------------------------------------

  FRONTEND
  --------
  - React 18               — Component-based UI with Hooks & Context API
  - Vite                   — Fast development server & optimized builds
  - Material UI (MUI) v5   — UI components, theming, sx styling
  - React Router v6        — Client-side routing with protected routes
  - Axios                  — REST API communication with JWT bearer tokens
  - Redux Toolkit          — Centralized game state management
  - Blockly                — Visual block-based programming editor (games)
  - Framer Motion          — Animations
  - Emoji Picker React     — Emoji support in Chat & Social Hub

  BACKEND
  -------
  - Node.js v18+           — JavaScript runtime
  - Express.js             — REST API server (port 5000)
  - MySQL                  — Relational database
  - mysql2                 — Lightweight MySQL driver
  - JWT (jsonwebtoken)     — Stateless authentication tokens
  - bcryptjs               — Password hashing
  - express-validator      — Input validation at API boundaries
  - node-cron              — Scheduled background jobs
  - Nodemon                — Auto-reload during development

  INFRASTRUCTURE
  --------------
  - XAMPP / MySQL          — Local database server
  - Vite Dev Server        — Frontend on port 5173
  - Express Server         — Backend on port 5000

MODULES & FEATURES
--------------------------------------------------------------------------------

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  1. AUTHENTICATION & SECURITY                                            │
  └──────────────────────────────────────────────────────────────────────────┘

  - JWT-based login for all roles
  - Separate faculty login flow (/faculty/login)
  - Passwords hashed with bcryptjs (salt rounds: 10)
  - Force password change on first login (must_change_password flag)
  - Role-based redirect after login
  - ProtectedRoute wrapper enforces allowedRoles on every page
  - Password reset by admins — generates a temporary password
  - User receives temp password and is forced to change it on next login
  - Audit logging for sensitive actions (password resets, role changes)
  - OWASP-aligned input validation on all API endpoints

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  2. SUPER ADMIN PANEL                                                    │
  └──────────────────────────────────────────────────────────────────────────┘

  Dashboard (/dashboard)
  - Platform-wide summary metrics
  - Quick navigation to all management sections

  Schools (/schools, /schools/:schoolId)
  - List all registered schools
  - View per-school details, user counts, subscription status

  Users (/users)
  - View and manage users across all schools
  - Filter by school, role, or status
  - Toggle user active/inactive status

  Role Management (/roles)
  - Create and manage roles with granular permission sets
  - Assign roles to users
  - RBAC permission checks throughout the app (PermissionContext)

  Subscriptions (/subscriptions)
  - Manage school subscription plans and tiers
  - View billing cycles and plan details

  Analytics (/analytics)
  - Platform-wide usage statistics
  - Date range filtering
  - Metrics: logins, active users, content created, engagement

  Templates (/templates)
  - Create reusable school page templates
  - Push templates to school admins for their school pages

  Announcements (/announcements)
  - Broadcast announcements to all schools or selected schools

  System Settings (/system-settings)
  - Platform-level configuration (features on/off, limits, etc.)

  Security (/security)
  - Security monitoring: failed logins, suspicious activity logs

  Password Management
  - SuperAdminPasswordManagement.jsx — admin can reset any user's password

  Classes (/faculty/classes)

  Students (/faculty/students)

  - Own profile: personal info, subjects, qualifications, bio

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  6. FORUM (Community Q&A)                                                │
  └──────────────────────────────────────────────────────────────────────────┘

  Access: school_admin, faculty, student

  Forum List (/forum)
  - Full-width layout with blue gradient header
  - Full-text search bar across all questions
  - Question cards: title, 200-char truncated preview, tag chips,
    answer count badge, author & date
  - Clickable cards navigate to question detail page

  Ask Question (Modal Dialog)
  - Title field (minimum 15 characters)
  - Question body textarea (6 rows)
  - Tags: add multiple, shown as deletable chips
  - Audience toggle: "For Students" or "For School"
  - Real-time quality score bar (0–100% based on title, body, tags)

  Question Detail (/forum/:questionId)
  - Full question: title, body, tags, author, timestamp
  - Helpful toggle (ThumbUp icon):
    * Grey = not yet marked by you → click to mark → turns blue
    * Counts update instantly, no page refresh
    * Each user can only vote once (UNIQUE constraint in DB)
    * Click again to remove vote (count decreases)
  - Delete button (red, author only):
    * Confirmation dialog before deleting
    * Soft delete (is_active = FALSE in DB)
    * Redirects to forum list after question delete
  - Reply editor: full-width textarea with embedded Reply button
  - Threaded/nested replies at any depth (4px indent per level)
  - Each reply: author, timestamp, helpful toggle, delete (author only)

  Database Tables
  - forum_questions  (id, title, body, tags, author_id, replies_count,
                      helpful_count, is_active, created_at)
  - forum_replies    (id, question_id, parent_reply_id, body, author_id,
                      helpful_count, is_active, created_at)
  - forum_helpful    (user_id, target_type ENUM('question','reply'),
                      target_id) — UNIQUE KEY prevents duplicate votes

  └──────────────────────────────────────────────────────────────────────────┘

  - Multi-tier subscription plans for schools
  - SubscriptionContext wraps entire app — any component can gate features

  │  12. RBAC (Role-Based Access Control)                                    │
  └──────────────────────────────────────────────────────────────────────────┘

  - RBAC routes: GET/POST/DELETE /rbac/users/:userId/roles
  - Permissions checked before UI elements render (hiding buttons for
    unauthorized users) AND at API level (double enforcement)

SETUP INSTRUCTIONS
--------------------------------------------------------------------------------

  1. Install MySQL (included with XAMPP) and start the MySQL service.

  2. Create the database:
        CREATE DATABASE eduima_db;

  3. Run the schema file:
        mysql -u root eduima_db < backend/database/schema.sql

  4. Create backend/.env:
        DB_HOST=localhost
        DB_USER=root
        DB_PASSWORD=
        DB_NAME=eduima_db
        JWT_SECRET=your-secret-key-here
        PORT=5000
        FRONTEND_URL=http://localhost:5173

  5. Install backend dependencies:
        cd backend && npm install

  6. Start the backend server:
        npm run dev

  7. Install frontend dependencies:
        cd frontend && npm install

  8. Start the frontend dev server:
        npm run dev

  9. Open browser: http://localhost:5173

  10. (Optional) Seed forum data:
        cd backend && npm run seed:forum
